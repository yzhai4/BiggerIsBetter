# 大就是强 · BiggerIsBetter

全球变异背景下的横向碰撞成长游戏。主角从农村老家的轮椅上出发，凭借“战胜对手就能变大变强”的异能一路战斗。

## 试玩与当前状态

- 原公开站点：https://big-is-strong.jimmy-vaughanowl.chatgpt.site/
- 版本管理仓库：https://github.com/yzhai4/BiggerIsBetter
- 对话中最后确认发布的是 Sites v15；这只是历史发布记录，不代表本仓库已获取其源码。
- 世界影响模块 0.1.0 是独立候选，尚未合并到原站点，也不能以它的测试场替换原游戏。
- 本仓库正在导入可验证的源码和测试。导入记录会明确区分“线上抓取快照”“独立实验模块”和“正式合并版本”。

## 本阶段范围

只打通现有 M 巨臂 / A 甲壳 / N 神经 / F 菌群的完整链路：即时能力变化 → 道路和敌人受影响 → 本轮后果 → 下一地区回响 → 死亡重开。

暂不增加新进化路线、大型分支剧情，也不启动正式图像、音乐与音效生产。

## 必须保留的设定

1. 全球陆地变异，从故乡乡野经县城、高楼封锁线走向前线；不能把背景改成水下。
2. 左向右推进，角色和敌人有明确的地面接触；手机少按钮、短文本、即时反馈。
3. 体型差决定撞飞、撞碎、碾碎、反击与致命后果，不是吞食。
4. Boss 通关后保留本局变异和世界后果；只重设显示标尺，不能把累计真实力量清零。
5. 死亡从最开始重开，清空本局变异与世界后果；不得误删既有局外成长。
6. 敌人显示尺寸与碰撞胜负必须可读，不能暗中改变质量却维持原提示。

## 版本约定

- `main`：项目索引、已审阅源码、导入与测试工具；不等同于已部署版本。
- `snapshot/*`：验证过来源的线上静态快照，不伪造原 Git 历史。
- `feature/*`：尚未上线的模块和集成工作。
- 每次发布记录来源提交、验证范围、部署目标、已知问题和回滚点。
- 不能因为“部署成功”或“语法检查通过”就声称已完成真实游玩验收。

仓库不保存账户凭证、访问令牌、Cookie、个人存档或部署密钥。公开页面抓取必须拒绝登录跳转，不绕过认证。GitHub 归档不会自动修改原站点。
