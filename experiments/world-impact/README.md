# 变异—道路—跨轮反馈 · 候选 0.1.0

**独立实验模块，尚未合并或部署到原公开游戏。** 这份源码来自本次对话已经交付的 `big-is-strong-world-impact-0.1.zip`，不是重新制作的 v15，也不能覆盖原站点首页。

## 运行

安装 Node.js 18 或更高版本和 Python 3。逻辑模块无第三方运行时依赖，不需要 `npm install`。

```sh
cd experiments/world-impact
npm run check
npm test
python build.py
```

打开生成的 `standalone.html` 即可离线体验；也可执行 `python -m http.server 8000`，访问本地 `http://localhost:8000/`。

## 内容

- `src/world-impact.js`：无 DOM 的四路线核心、道路状态、世界后果、显示标尺与跨轮继承。
- `src/host-hooks.js`：宿主适配接口。正式游戏仍是质量、伤害、胜负和存档的唯一权威。
- `src/demo.js`、`index.html`：独立交互验收场，Boss 按钮明确标为模拟。
- `tests/*.test.cjs`：60 项逻辑和宿主合同测试。
- `tests/browser-checks.py`：可选本地 Chromium 触控/布局/继承检查，不等于真机。

## 已有四路线

M 震裂道路并打断追击；A 架壳减伤并留下可利用壳片；N 放电干扰追击并使设施复电；F 铺设菌毯、减速追击者并在胜利后反哺体力。场景使用同一份路面状态呈现结果，下一地区保留来源与后果。

只有非致命碰撞可获得 A 的减伤；致命体型差仍然致命。玩家和敌人使用同一显示缩放，跨轮保留绝对力量，仅重建显示基准。死亡重开清空本局因果，不接触旧游戏局外存档。

## 接入边界

当前没有原站点 v15 的完整源码，因此未宣称合并完成。正式接入还必须审计旧存档、原爆发按钮、异化节点和濒死复苏；防止双重扣血、重复回血、模拟按钮上线，以及把屏幕归一化误写成力量清零。

不要把验收场当正式游戏，不新增进化路线或大型剧情，不启动正式美术/音频生产。
